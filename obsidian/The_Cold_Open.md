{Campaigns in *Misfits* begin with a cold open. Turns out its boring to do a bunch of exposition right at the start}

Your GM will start a Situation that is implied to have been going on for some time before the actions you take. The Situation runs exactly the same as any other situation, with the following modifications:

In addition to other start-of-Situation effects, each player should make a Whim roll. In addition to the normal scoring, each player may pay 2 mana to score an additional instance of Arcana. Each player then chooses 5 minus their score of the following downsides, which can be chosen more than once:

- Start with a Minor Injury
- Start with -1 Focus
- Start with -4 Mana
- Start with -1 AP (Take this only if you were allocated one)
- Start with some kind of incapacitation; blinded, deafened, restrained, etc. up to GM discretion.
